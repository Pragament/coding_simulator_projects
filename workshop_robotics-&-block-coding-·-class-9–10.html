Variables

stores a value your robot can change

A variable is a named memory slot in your robot's brain. Instead of writing the number 82 everywhere in your program, you store it in a slot called battery_level — and the program reads whatever is in that slot right now.

set battery_level to 82
change battery_level by −5

Random Number Generation

unpredictable, on purpose

Sometimes you want your robot to be unpredictable — picking a random direction to turn if it hits a wall, or a random delay before it moves. A random block picks a number between a low and high value, and you can't know which one in advance.

set turn_angle to pick random 30 to 90

03

Conditional Statements (If–Else)

branching decisions

An if–else block lets your robot choose between two paths depending on a sensor reading. If the condition is true, run one set of blocks; otherwise (else), run a different set. Only one branch ever runs.

if light_sensor < 50 then
  turn on headlights
else
  turn off headlights

Try it — drag the light sensor reading

04

Modulus Operator (%)

the remainder after division

% gives you what's left over after dividing one number by another. Robots use it constantly — e.g. checking if a step counter is a multiple of 4 to know when to blink an LED, or telling even numbers from odd ones.

set remainder to (steps mod 4)

Comparison Operators

true or false, always

Comparison operators (>, <, =, ≥, ≤, ≠) compare two values and always produce a boolean — true or false. These are what feed the condition inside an if-block.

Try it — build a comparison

06

Events

the trigger that starts a program

An event is something that happens — a button press, a bump, a timer — that starts a block of code running. Your program sits and waits (listens) until the event fires, rather than running top to bottom immediately.

when bump_sensor is pressed
  move backward 1 second

07

Input

bringing outside data into the program

Input is how your program receives data — from a sensor, a keypad, or a user typing something. The program pauses, waits for the value, then stores it in a variable to use later.

ask "What's your name?" and wait

Try it — give the program some input

08

Output

what the program shows back

Output is the flip side of input — the program sends information back out, whether that's text on a screen, an LED turning on, or a motor spinning. Every output block adds one more line to what the world sees.

say "Hello, ready to roll!"

09

Loops

repeat without rewriting

A loop repeats a block of code a set number of times, or until a condition changes. Instead of copy-pasting "move forward" ten times, wrap it in a repeat 10 block.

repeat 6 times
  move forward 1 step

Try it — watch a loop run

Counters

a variable that keeps score

A counter is just a variable, usually starting at 0, that goes up (or down) by a fixed amount each time something happens — laps completed, obstacles avoided, points scored.

set laps to 0
change laps by 1
